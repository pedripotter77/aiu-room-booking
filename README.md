# aiu-room-booking
Веб-система бронирования аудиторий для Astana International University (AIU). Проект представляет собой full-stack приложение с REST API на Go, СУБД PostgreSQL и интерактивным пользовательским интерфейсом.

---

## Технологический стек

* **Backend:** Go (Golang)
* **Database:** PostgreSQL
* **Frontend (In Progress):** HTML5, CSS3, JavaScript (ES6+)
* **UI/UX Design:** Figma
* **Drivers & Libraries:** `github.com/lib/pq`, `github.com/joho/godotenv`
